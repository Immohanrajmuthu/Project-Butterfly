# Project Constitution

The following doctrines are the permanent foundation of Project ButterFly.

Every charter, standard, guideline, and implementation must align with these principles.

These doctrines are intentionally few, memorable, and timeless.

## The Doctrines

>> Purpose Before Code

>> Comfort Before Conversion

>> Confidence Before Completion

>> Calm is Beautiful

>> Every Feature Must Earn Its Place

>> Inclusion Before Compliance

>> Engineering Serves Experience


**No document within Project ButterFly may contradict these principles.

If a conflict arises, the Constitution takes precedence.**
