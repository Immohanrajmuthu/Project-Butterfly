# 🦋 Documentation Assets

This directory contains visual resources used throughout the Project ButterFly documentation.

Examples include:

- Logos
- Repository banners
- Icons
- Diagrams
- Illustrations
- Architecture images

Assets should support the documentation without becoming the documentation.

---

Recommended Structure

assets/

logos/

banners/

icons/

diagrams/

screenshots/

---

Keep assets organized, optimized, and easy to reuse.
