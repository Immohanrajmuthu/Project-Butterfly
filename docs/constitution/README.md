# 🦋 Constitution

> **The Foundation of Project ButterFly**

The Constitution is the highest authority within Project ButterFly.

It defines the permanent principles that guide every decision throughout the methodology.

Unlike Charters, Standards, and Guides, the Constitution is intentionally stable.

Technology evolves.

Engineering practices improve.

Products grow.

The Constitution endures.

---

# The Role of the Constitution

The Constitution answers one timeless question:

> **What principles should never change?**

Everything else within Project ButterFly builds upon the answer to that question.

Every Charter.

Every Standard.

Every Guide.

Every Reference Implementation.

Every future contribution.

If a conflict arises, the Constitution always takes precedence.

---

# Relationship to the Methodology

Project ButterFly is designed as a progressive engineering methodology.

```text
Constitution
        ↓
Charters
        ↓
Standards
        ↓
Guides
        ↓
Reference Implementations
```

Each layer has a different responsibility.

| Layer | Question |
|--------|----------|
| Constitution | What principles should never change? |
| Charters | What do we believe? |
| Standards | How should we work? |
| Guides | How do we apply it? |
| Reference Implementations | What does it look like in practice? |

Everything begins with the Constitution.

---

# Characteristics

The Constitution is intentionally:

- Timeless
- Technology-agnostic
- Principle-driven
- Stable
- Memorable
- Concise

It should rarely change.

Its role is not to describe implementation.

Its role is to preserve identity.

# Reading Guidance

The Constitution should be read before any other Project ButterFly document.

It establishes the principles that give meaning to every Charter, Standard, Guide, and Reference Implementation that follows.

Understanding the Constitution makes the rest of the methodology easier to understand.

---

# Looking Ahead

The Constitution establishes enduring principles.

The Charters explain the philosophy behind those principles.

The Standards transform philosophy into consistent engineering practices.

The Guides teach engineers how to apply those practices.

Reference Implementations demonstrate the complete methodology in real software.

Together, they form the complete Project ButterFly journey.

# Closing Thought

Principles outlive products.

They outlive technologies.

They even outlive the teams that first created them.

That is why every journey through Project ButterFly begins with the Constitution.
