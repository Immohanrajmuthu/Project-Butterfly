# 🦋 Decisions

> **Preserving the Why**

Project ButterFly uses Architecture Decision Records (ADRs) to document significant decisions that shape the evolution of the methodology.

Unlike Standards, which describe repeatable engineering practices, Decision Records explain **why** important choices were made.

Every ADR captures the context, alternatives considered, the final decision, and its consequences.

Together, these records preserve the reasoning behind Project ButterFly as it evolves.
