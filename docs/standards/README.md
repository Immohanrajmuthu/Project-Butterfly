# 🦋 Standards

> **From Principles to Practice**

The Standards of Project ButterFly answer one important question:

> **How do we consistently apply our philosophy?**

The Constitution defines our enduring principles.

The Charters explain what we believe.

The Standards transform those beliefs into consistent, repeatable engineering practices.

Unlike the Constitution, which is intended to remain timeless, Standards may evolve as engineering practices, technologies, and teams evolve.

Their purpose is not to restrict creativity.

Their purpose is to reduce unnecessary decisions, improve consistency, and help teams build software with confidence.

# Relationship to the Methodology

Project ButterFly is designed as a progressive engineering methodology.

```text
Constitution
        ↓
Charters
        ↓
Standards
        ↓
Guides
        ↓
Reference Implementations
```

Each layer answers a different question.

| Layer | Question |
|--------|----------|
| Constitution | Why do we exist? |
| Charters | What do we believe? |
| Standards | How should we work? |
| Guides | How do we apply it? |
| Reference Implementations | What does it look like in practice? |

Together, these layers transform philosophy into practical engineering.

---

# Characteristics of a Good Standard

Every Project ButterFly Standard should:

- Explain **why** before **how**.
- Be technology-agnostic whenever possible.
- Encourage thoughtful engineering rather than rigid processes.
- Reduce repeated decision-making.
- Improve long-term consistency.
- Remain understandable for future contributors.

Standards should teach principles that outlast individual tools and frameworks.

---

# When to Create a New Standard

A new standard should exist only when it helps teams make better decisions repeatedly.

Before creating a new standard, ask:

- Does it solve a recurring problem?
- Will it improve consistency across projects?
- Can it be applied broadly?
- Does it align with the Constitution and Charters?
- Will it remain valuable as technology evolves?

If the answer is yes,

the standard belongs in this collection.
