# 🦋 Guide Roadmap

> **The complete learning journey of Project ButterFly**

The Guides Edition transforms the principles and standards of Project ButterFly into a structured engineering learning experience.

Rather than presenting isolated tutorials, the guides form a connected journey where each guide builds upon the previous one. Every guide teaches an engineering concept, encourages practical application, and produces one or more reusable engineering artifacts.

By completing the Guides Edition, readers will not only understand Project ButterFly—they will be able to apply it to real-world software projects.

---

# Purpose

The Guide Roadmap serves as the architectural blueprint for the Guides Edition.

It defines:

- The complete learning journey
- The purpose of every guide
- The relationship between guides
- The engineering artifacts created throughout the journey
- The progression from idea to production-ready software

---

# Who Should Read These Guides?

The Guides Edition is designed for anyone who wants to build thoughtful software.

This includes:

- Software Engineers
- QA Engineers
- Accessibility Engineers
- Technical Leads
- Software Architects
- Product Engineers
- Startup Founders
- Computer Science Students
- Open Source Contributors
- Anyone passionate about software craftsmanship

Project ButterFly is intentionally technology-agnostic.

The methodology focuses on engineering principles rather than programming languages or frameworks.

# Learning Philosophy

Project ButterFly follows a continuous learning cycle.

```text
Reflect
    ↓
Learn
    ↓
Apply
    ↓
Create
    ↓
Verify
    ↓
Reflect
    ↓
Continue
```

Every guide follows this philosophy.

Readers are encouraged to think critically, build practical artifacts, verify their work, and continuously improve.
