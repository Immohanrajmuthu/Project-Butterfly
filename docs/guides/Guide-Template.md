# 🦋 Guide Template

> **A reusable template for creating Project ButterFly Guides**

Every guide should leave the reader with greater clarity than when they began, and with at least one engineering artifact they can immediately use in their own project.

This template defines the standard structure for every guide within Project ButterFly.

Every guide should help readers:

- **Learn** a concept.
- **Apply** it through practical activities.
- **Create** a reusable engineering artifact.

Together, the guides form a structured engineering journey from idea to production-ready software.

---

# Guide Quality Checklist

Every Project ButterFly Guide should be:

- ✅ Timeless
- ✅ Practical
- ✅ Actionable
- ✅ Reusable
- ✅ Verifiable
- ✅ Purpose-Driven

If a guide does not satisfy these principles, it should be refined before publication.

---
